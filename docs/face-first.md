# 얼굴·음성 기본 화면 + 단일 페르소나 (chaeti-v1.6-face-first)

## 화면
- 접속 → 「탭해서 채티 깨우기」 오버레이 (브라우저가 마이크/TTS에 사용자 제스처를 요구해서 한 번은 눌러야 함) → 얼굴 크게 + 음성 대화(ko-KR) 시작. 「그냥 글로 할래」를 누르면 얼굴 + 글 입력으로 시작.
- 글 패널(`#textPanel`: 로그·입력창·출처)은 기본 숨김. 헤더 「글」 버튼으로 언제든 열고, 「얼굴로 돌아가기」로 닫음.
- 자동으로 열리는 경우
  - `/chat` 응답 `ui.show_text` — 코드·링크·목록·긴 답·출처가 있거나, 계획 단계가 `display:"text"`로 판단했거나, 유저가 "코드/링크/목록/정리해/써줘…"를 말했을 때
  - `ui.need_input` (`url` | `text` | `code`) — 채티가 URL·긴 글·코드를 받아야 할 때. 입력창에 포커스, 힌트 표시, **마이크는 보낼 때까지 잠깐 쉼**(타이핑이 받아쓰기되지 않게)
  - `/browse` 결과(타임라인·출처)는 항상 글로
  - 타이핑으로 보낸 턴
- 자동으로 열린 패널은 음성이 켜져 있고 60초 동안 안 만지면 얼굴로 돌아감. 직접 연 패널은 안 닫힘.
- 음성 읽기: 코드 블록은 안 읽고, "짧은 말 \n\n 상세" 형식이면 상세(링크·목록·긴 내용)는 글로만 보여주고 앞부분만 읽음. URL은 "링크"로 읽음.

## 단일 페르소나
- 비서/RP 토글 삭제. 워커는 `ui_mode`를 무시하고 항상 채티(RP) 프롬프트에 "비서이기도 하다 — 검색·웹·코딩·정리·기억·시간" 역할 줄을 넣음. 음성 중이면 "1~3문장 + 상세는 줄바꿈 두 번 뒤" 지시.
- `/browse` 에이전트의 `done` 요약도 채티 말투(사실·출처는 정확히).
- 라우팅 축소(`task.js`·`app.js` 동일): 뉴스·날씨·가격·"검색해" 같은 조회는 `/chat`(자동 웹 검색)이 답하고, **브라우저에서 할 행동**(열어/로그인/배포/클릭/가입/예매/커밋…)·URL·"자세히 조사해/비교해/리서치"·`/웹` 접두만 `/browse`로.

## 응답 필드
