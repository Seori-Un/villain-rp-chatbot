# 아는 척 안 하기 (chaeti-v1.9-honest)

세 겹으로 막는다.

**1. 답하기 전 — 모르는 걸 먼저 안다** (`think.js` + `truth.js evidenceGaps`)
- 계획 단계가 `knowledge`를 분류: `common`(상식) / `web`(최신·특정 사실 → 자동 검색) / `memory`(이 사람과의 과거) / `unknowable`(사적인 일·미래·남의 속마음) / `none`.
- needs_web 기준을 넓힘: 구체 수치·고유명사·"~이 뭐야/누구야/언제야/얼마야"는 검색. 애매하면 검색 ("찾아보는 게 아는 척보다 낫다").
- 검색이 필요했는데 결과가 없음 / 과거를 묻는데 기억에 없음 / 알 수 없는 것 → 프롬프트에 **【모르는 것】** 블록: "단언하지 말고 모른다고 해라, 지어내지 마라".
- 페르소나에 성격으로 박음: "채티는 아는 척을 제일 싫어한다 — 이 사람한테만은 절대 안 속인다. 몰라/찾아볼게/네가 말해 줘야 알지/아마/기억 안 나."

**2. 답한 뒤 — 양심 검사** (`truth.js verifyAnswer`)
- 답에 숫자·날짜·고유명사·"기억나/말했잖"이 있거나, 검색·기억이 걸린 턴만 검사(잡담은 건너뜀, 비용 0).
- 별도 호출이 답에서 '사실처럼 말한 것'을 뽑아 근거(웹 자료·기억·상대 말)와 대조: `supported / common / hedged / unsupported / fabricated_memory`.
- `unsupported`·`fabricated_memory`가 하나라도 있으면 **【다시 말하기】** 블록을 붙여 같은 감정·말투로 한 번 다시 답하고, 이전 답은 대화 기록에서 교체.
- 응답 `truth: {claims, unsupported, revised}` → 말풍선 밑 칩: "사실 확인 3" / "근거 없던 말 2개 → 고쳐 말함". 펼치면 주장별 판정.
- `CHAT_TRUTH=0`으로 끔.

**3. 웹 조사 요약** — "읽은 페이지에 없는 사실은 쓰지 않는다. 못 찾았으면 '못 찾았어'가 정답."

비용: 사실이 섞인 턴에 호출 1회 추가(검사), 걸리면 1회 더(재답변). 감정 잡담은 그대로.
